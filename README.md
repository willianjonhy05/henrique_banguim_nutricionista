# 🥗 Henrique Banguim | Nutricionista

Landing page profissional desenvolvida para apresentação dos serviços do nutricionista **Henrique Banguim**, com foco em **emagrecimento, performance e saúde**.

---

## 🚀 🔥 Sobre o Projeto

Este projeto consiste em um site institucional moderno, responsivo e otimizado para conversão, com o objetivo de:

- Apresentar os serviços do profissional
- Gerar leads via WhatsApp
- Fortalecer a presença digital
- Transmitir autoridade e confiança

---

## 🧠 💡 Tecnologias Utilizadas

- HTML5
- CSS3 (com variáveis e responsividade)
- JavaScript (interatividade e animações)
- Font Awesome (ícones)
- Google Fonts

---

## 🎯 ⚙️ Funcionalidades

- ✅ Layout responsivo (mobile-first)
- ✅ Menu mobile interativo
- ✅ Animações com scroll (reveal)
- ✅ Botão flutuante do WhatsApp
- ✅ Sessões organizadas:
  - Hero (apresentação)
  - Sobre
  - Serviços
  - Depoimentos
  - Blog
  - Contato
- ✅ SEO básico implementado
- ✅ Meta tags para redes sociais (Open Graph + Twitter)

---

## 📱 📲 Integrações

- WhatsApp para agendamento direto
- Links para redes sociais (Instagram e Facebook)

## 🎨 🎯 Design

O design segue uma abordagem:

- Minimalista
